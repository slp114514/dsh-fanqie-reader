# 番茄书虫 · dsh-fanqie-reader

> 带左侧栏入口的 DSH 插件：在 DeepSeek Harness 里读番茄免费小说，并把「和 DeepSeek 共读」这件事**限定在一个你指定的会话**里。

---

## 它做什么

- **左侧栏入口**：`sidebar.panellist` 里的「番茄书虫」，点开是主面板阅读器。
- **书架 / 阅读器**：粘贴番茄书籍链接、书籍 ID，或按书名搜索；目录、上一章/下一章、阅读进度、深色/浅色主题自适应。
- **DeepSeek 共读工具**：`fanqie_search`、`fanqie_book`、`fanqie_toc`、`fanqie_read`、`fanqie_shelf`。
  - 可以搜书、看书籍信息、读目录、读正文、管理书架。
  - 正文来自番茄网页公开内容，并会还原番茄的动态字体（PUA）映射，不会得到一串乱码。
- **番茄账号扫码登录**：设置 →「番茄账号」→「扫码登录」，用番茄/抖音 App 扫码。
  - 登录 Cookie 只保存在本机，不返回给前端。
  - 登录后可以读取账号本来就有权限的章节。
  - 也保留了手动粘贴 Cookie 的备用入口。
- **App 评论 / 回复（实验性）**：用你本机已登录的番茄 App 账号，在书评下发布书评、回复书评。
  - 新增工具：`fanqie_comments`、`fanqie_comment`、`fanqie_reply`。
  - 设置页的「评论与回复」卡片也可以手动发。
  - 仅使用本机已捕获的账号会话；每天上限和两条之间的最小间隔都可以在设置里自己调（默认 10 条/天、20 秒）。
  - 书评列表接口对重放签名较严格；当前会回退到本机最近一次捕获的书评快照。写接口（书评/回复）已实测可用。
- **会话隔离（重点）**：在侧栏「共读会话」里选一个已有 DSH 会话，或新建「番茄共读」。
  - 只在这个会话的 Agent 上注册 `fanqie_*` 工具；其他会话**看不到**这些工具。
  - 阅读器里的「AI 共读这一章」会往绑定会话发送一条消息，让 DeepSeek 先调用 `fanqie_read` 再和你聊。
  - 换绑/解绑会同步卸载旧会话的工具。

## 安装

### 从 npm / 插件市场安装

发布到 npm 后，可以直接从插件市场安装，或在 DSH 里执行：

```bash
dsh plugin --profile desktop add dsh-fanqie-reader
```

安装后完整重启 DSH，再刷新页面，左侧栏会出现「番茄书虫」。

### 本地开发

这是一个本地 bundle。把本目录作为插件包安装到当前 profile，例如在 DSH 里让助手执行 `plugin_manager install_bundle`（target 用本目录的绝对路径），或：

```bash
dsh plugin --profile desktop add <本目录的绝对路径>
```

安装后**完整重启 DSH**（bundle 层需要重启组装），再刷新页面。左侧栏会出现「番茄书虫」。

> 当前工作区里的默认目录：`C:\Users\slp114514\Documents\deepseek-harness\default-workspace\dsh-fanqie-reader`

## 使用

1. 点左侧栏「番茄书虫」。
2. 粘贴一个番茄书籍链接，例如 `https://fanqienovel.com/page/7069948840148732967`，或输入书籍 ID。
   - 也可以输入书名搜索，但番茄站内搜索需要登录态；插件走的是网页索引，结果可能有限。搜不到时请直接粘贴链接或 ID。
3. 打开书后，目录/正文会显示在阅读器里；阅读进度会自动保存。
4. 点上方的「选择会话」：
   - 选一个已有会话，或点「新建共读会话」。
   - 绑定后，去那个会话里和 DeepSeek 说话；只有它能用 `fanqie_*` 工具。
5. 在阅读器里点「AI 共读这一章」，会向绑定会话发一条消息，让 DeepSeek 读取本章并和你讨论。

## App 评论桥的额外前提

书评/回复走番茄 App 的私有接口，需要：

1. 一个 64 位 Android 模拟器（本插件开发时用 BlueStacks Nougat64），安装并登录番茄 App。
2. 模拟器 root + 系统证书（用于抓取一次你自己的 App 会话）。
3. 把抓到的会话保存到 `$DSH_HOME/fanqie-reader/device-auth.json`（权限 0600）。
   该文件包含 cookie 与设备签名头，**不要分享、不要提交到仓库**；删除它即可断开 App 互动功能。

插件不会创建账号、不会绕过登录、不会读取别人的私信；只代表你自己已登录的账号发言。

## 高级互动组件（可选，BlueStacks）

开启自动书评/回复需要在本机安装 **BlueStacks 5（免费版）** 并创建一个 Android 实例。

- 首次安装需要 **一次 Windows 管理员授权**（用于虚拟化/驱动），之后不再需要。
- 免费版可能显示欢迎页、广告或更新提示；插件会**自动隐藏或尝试关闭**，不影响番茄阅读和评论。
- 如果仍有窗口残留，你可以直接关掉，不影响已经连接好的账号。
- 不安装高级组件也可以使用阅读、书架和 AI 草稿；只有「自动发布」需要它。

插件设置里的「自动互动设置」可以调：

- **AI 直接发布**：开启后 AI 不再逐条确认；仍受上限和间隔限制。
- **每天最多**：1～50 条。
- **最小间隔**：5～300 秒。

自动发布始终只使用你自己的账号，且不会绕过番茄的登录/风控。

## 运行时间（默认 DeepSeek 谷时）

设置里的「运行时间」控制隐藏桥什么时候启动：

- 默认 **北京时间 00:30–08:30**（DeepSeek 谷时），每天运行
- 可以改开始/结束时间，以及周一～周日
- 到点自动在 **Windows 隐藏桌面**启动 BlueStacks，用户看不到播放器/管理器
- 结束后自动停止，释放 CPU
- 不在时段内不会启动；手动「立即启动」可临时覆盖，停止后回到时间表
- 隐藏桥会枚举隐藏桌面窗口，自动关闭 BlueStacks 的欢迎页/广告/更新提示；主播放器窗口不会被误关

目前隐藏启动和到点自动启停已经实测；真实广告窗口的自动关闭还需要在实际弹出时继续校准标题/类名。

## 关于番茄页面

- 插件只请求 `fanqienovel.com` 的公开页面与目录接口；不绕过登录、付费或 SVIP 限制。
- 番茄网页对未登录/非 SVIP 读者可能只返回**试读**；结果里会明确标 `locked: true`，阅读器也会显示「这一章网页端只返回了试读」。
- 侧栏「设置」里可以粘贴你自己的番茄 Cookie（可选），它只保存在本机并只发送给 `fanqienovel.com`，用于读取你账号本来就有权限的内容。留空/点「清除」即可删除。
- 字体映射与解析是社区逆向整理的；番茄改版后可能需要更新 `fanqie-font.js`。

## 数据与隐私

- 书架、进度、绑定会话、可选 Cookie 都存在：
  `$DSH_HOME/fanqie-reader/state.json`
- 插件不把 Cookie 返回给前端；API 只返回 `cookieSet: true/false`。
- 除了番茄页面和可选的搜狗网页索引，不访问其他站点。
- 插件不主动调用 LLM；只有你点「AI 共读这一章」时，才会向绑定会话发送一条用户消息（消耗该会话 token）。

## 会话隔离是怎么做的

- 插件监听 `agent/created`，只在 `agent.id === boundSessionId` 时，通过 `agent.ctx.effect()` 在该 Agent 的 scope 里注册工具与共读 system context。
- 绑定变化时 `syncBinding()` 会卸载旧 Agent 的工具，再给新 Agent 注册。
- 工具执行时还会再次检查 `exec.agent === agent`，防止意外串会话。
- 因此：**其他会话的模型连工具名都看不到**，不是只在提示词里“请求”它别用。

## 已知限制

- 番茄站内搜索依赖登录态，网页索引不保证搜得到；链接/ID 是最稳的入口。
- 网页端锁定章节只能读试读；设置自己的 Cookie 可能改善，但不保证。
- 多章连续阅读会逐章请求番茄；请求有缓存与重试，但番茄限流时仍可能失败。
- 阅读器是主面板 UI，不是独立窗口；左侧栏入口和主面板通过同一个 id 关联。
- 当前版本没有自动追更/定时共读；以手动阅读 + 指定会话共读为主。
- App 书评列表接口的重放签名会过期；写接口可用，但列表可能只能读到最近一次本机快照。要完全自动“监控新书评并逐条回复”，仍需要新的 App 抓包会话。
- 自动发评论/回复只覆盖书评，不包含私信；这是按你的要求砍掉的。
- 一键安装 BlueStacks 的安装器还没做；目前需要本机已有 BlueStacks 实例，隐藏启动器只负责“无窗口启动/停止”。首次安装仍需一次管理员授权。
- 免费版 BlueStacks 的宿主弹窗会被隐藏桌面遮住，插件也会尝试关闭；不是商业版那种彻底无广告。

## 开发

```bash
node --check index.js
node --check fanqie.js
node --check client.js
node --check trust.js
```

文件：

- `index.js`：Host 半端；HTTP 路由、状态、会话绑定、按 Agent 注册工具。
- `auth.js`：番茄网页扫码登录（passport QR + Cookie 保存）。
- `fanqie.js`：番茄页面/目录/正文解析、搜索、输入解析。
- `fanqie-app.js`：番茄 App 评论/回复桥（本机会话 + 写接口）。
- `bridge.js`：隐藏桥控制器 + 运行时间调度。
- `bridge-hidden.ps1`：Windows 隐藏桌面启动器 + 关窗循环。
- `fanqie-font.js`：番茄动态字体 PUA -> 汉字映射。
- `client.js`：左侧栏入口 + 阅读器 React 面板。
- `trust.js`：本地路由的 Host/Origin/Sec-Fetch-Site 围栏。
